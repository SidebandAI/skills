# Sideband skills

Agent skills for [Sideband](https://www.sideband.ai). Connecting the MCP server is not enough — install this skill so the agent knows how to draft pulses and keep project context current.

## Install

**Coding agents**

```bash
npx skills add SidebandAI/skills
```

**Claude Desktop and claude.ai**

1. Turn on code execution (Settings → Capabilities).
2. Download the latest zip: https://github.com/SidebandAI/skills/releases/latest/download/sideband.zip
3. Customize → Skills → Upload a skill.

The zip is rebuilt on every push to `main`.
